## 1. Plan Overview & Objectives
This plan implements hardware NFC tag scanning in the KiddoChecker kiosk application to enable high-throughput, contactless, $0-typing check-in and out. Tapping a physical NFC token will immediately authenticate a parent or staff member.

## 4. Verification & Testing Playbook

### Step 1: Run the Backend server and confirm migration
```powershell
node server/index.js
```
Expected output:
`[DB] Migration SUCCESS: col_nfc_uid`

### Step 2: Run the Frontend dev environment
```powershell
npm run dev
```

### Step 3: Execute Kiosk NFC E2E UAT test script
1. Navigate to `/kiosk` or mount `KioskCheckInSystem`.
2. Observe the NFC status indicator in the top header.
3. Tap or enter a mock serial number (`SIMULATED-NFC-PARENT-101`).
4. Toast displays: "NFC Tag Unrecognized" (confirming active lookup).
5. Open Staff Page, register this NFC tag to a staff member or parent profile.
6. Re-tap the mock NFC card.
7. Observe instant screen transition to family check-in selection or staff portal without manual input!
